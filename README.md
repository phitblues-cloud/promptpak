# PROMPT PAK — ระบบจริง เฟส 1

PMS + AI สำหรับโรงแรมเล็ก (โรงแรมทดสอบ: พบรักรีสอร์ท)

**ทำได้แล้ว**
- ลูกค้าทัก LINE OA → AI (Claude) เช็คห้องว่างจริง → สรุปราคา → ลูกค้ายืนยัน → สร้างการจองจริง
- การจองขึ้นทันทีใน: หน้าแรก (เช็คอิน/เข้าพัก/เช็คเอาท์), ปฏิทินการจอง, รายการการจองทั้งหมด
- AI สรุปให้เจ้าของ (อ่านการจอง + แชทจริง ≤ 5 ข้อ)
- หน้าแชท LINE: ดูบทสนทนา AI ↔ ลูกค้า, เรื่องที่ AI ส่งต่อพนักงาน, ปุ่ม "จบเรื่อง"
- ล็อกอินจริง (Supabase Auth)

**ราวกันตก**
1. ฐานข้อมูลปฏิเสธการจองทับห้องคืนเดียวกันเอง (exclusion constraint)
2. AI จองได้เมื่อข้อมูลครบ (ชื่อ เบอร์ วันเข้า-ออก ประเภท/จำนวนห้อง) และลูกค้ายืนยันแล้ว
3. 5 ห้องขึ้นไป / เครดิตบริษัท / ส่วนลด / ยกเลิก-แก้ไข → ส่งต่อพนักงาน (AI จองเอง > 4 ห้องไม่ได้ ฐานข้อมูลบล็อก)

**โครงสร้าง**
```
public/        หน้าเว็บ (HTML ธรรมดา)
api/           หลังบ้าน (Vercel Functions)
lib/           ฐานข้อมูล / LINE / AI / ล็อกอิน
supabase/      01_schema.sql (ตาราง+ฟังก์ชัน), 02_seed.sql (ข้อมูลตัวอย่าง)
tests/run.mjs  ทดสอบทั้งเส้นทางในเครื่อง (14 ข้อ)
SETUP.md       คู่มือติดตั้งทีละขั้น
```

**ยังไม่ทำ (backlog):** เช็คอิน/เช็คเอาท์ในระบบ, เช็คอินผ่าน LINE, แม่บ้านตรวจห้องผ่าน LINE, การเงิน/ใบกำกับภาษี, แก้/ลากการจองบนปฏิทิน, พนักงานตอบแชทจากเว็บ, การตลาด/CRM จริง
