# PROMPT PAK — ระบบจริง เฟส 1

PMS + AI สำหรับโรงแรมเล็ก (โรงแรมทดสอบ: พบรักรีสอร์ท) · **หน้าจอคือต้นแบบ v196 เดิมทุกอย่าง** เปลี่ยนเฉพาะแหล่งข้อมูลเป็นฐานข้อมูลจริง

**ทำได้แล้ว**
- ลูกค้าทัก LINE OA → AI (Claude) เช็คห้องว่างจริง → สรุปราคา → ลูกค้ายืนยัน → AI ยืนยันการจองเอง
- การจองเข้า **จัดการการจอง** (ปฏิทิน + การจองทั้งหมด) ทันที (~10 วินาที) และขึ้นการ์ด **เช็คอิน** ที่หน้าแรกเมื่อถึงวันเข้าพัก
- แชทจริงขึ้นใน **แชทลูกค้า LINE**
- กล่อง **สถานการณ์ลูกค้าตอนนี้** (CRM › ภาพรวมลูกค้า) ใช้ผลวิเคราะห์จาก AI จริง
- หน้าล็อกอินเดิม + **PIN** (เจ้าของ / พนักงาน) · ก่อนใส่ PIN ไม่มีข้อมูลลูกค้าส่งไปที่เครื่อง
- สถานะการพักคำนวณจากวันที่จริงทุกวัน (รอเช็คอิน / กำลังพัก / เช็คเอาท์)

**ราวกันตก**
1. ฐานข้อมูลปฏิเสธการจองทับห้องคืนเดียวกันเอง
2. AI จองได้เมื่อข้อมูลครบและลูกค้ายืนยันแล้ว
3. 5 ห้องขึ้นไป / เครดิตบริษัท / ส่วนลด / ยกเลิก-แก้ไข → ส่งต่อพนักงาน (AI เงียบ 6 ชั่วโมง)
4. ใส่ PIN ผิด 8 ครั้ง ล็อก 15 นาที

**ข้อจำกัดเฟสนี้:** สิ่งที่พนักงานกดในหน้าจอ (เพิ่มการจองเอง เช็คอิน ฯลฯ) ยังเป็นการทำงานแบบต้นแบบ รีเฟรชแล้วหาย · รายงาน/CRM/การตลาดยังอิงข้อมูลตัวอย่างเป็นหลัก

**โครงสร้าง**
```

api/app.py     หน้าเว็บหลัก (Python)
api/*.js       LINE webhook, AI สรุป, ตรวจการตั้งค่า
lib/           ฐานข้อมูล / LINE / AI
supabase/      01_schema.sql, 02_seed.sql
tests/run.mjs  ทดสอบทั้งเส้นทาง (18 ข้อ)
SETUP.md       คู่มือติดตั้ง
```
