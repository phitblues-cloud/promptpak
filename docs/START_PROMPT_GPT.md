สวัสดี ฉันกำลังส่งต่องานโปรเจกต์ PROMPT PAK (ระบบบริหารโรงแรมเล็ก + AI + LINE OA) ที่ใช้งานจริงแล้วที่ https://promptpak-eight.vercel.app โค้ดอยู่ใน GitHub: phitblues-cloud/promptpak

ขอให้ทำตามนี้ก่อนทำอย่างอื่น
1. อ่านไฟล์ AGENTS.md ใน repo ให้จบทั้งไฟล์ (มีกติกา สถาปัตยกรรม วิธีทดสอบ และงานค้าง)
2. สรุปให้ฉันฟังเป็นภาษาไทยง่ายๆ ไม่เกิน 10 บรรทัด ว่าเข้าใจระบบว่าอะไร อะไรใช้งานจริงแล้ว อะไรยังไม่ใช่ของจริง
3. ฉันไม่มีพื้นฐาน IT และใช้ iPad อย่างเดียว ให้อธิบายแบบคนไม่ใช่สายเทคนิค ถ้าไม่เห็นด้วยหรือมีความเสี่ยงให้ค้านตรงๆ พร้อมตัวเลข
4. ห้ามเปลี่ยนหน้าตาโมดูลเดิมถ้าฉันไม่ได้สั่ง ห้ามใส่รหัสลับในไฟล์ และก่อน push ทุกครั้งต้องรัน `node tests/run.mjs` ให้ผ่านครบ (push เข้า main = เว็บจริงเปลี่ยนทันที)
5. ส่งไฟล์พิตช์ 28 ต.ค. ขึ้นเวที 31 ต.ค. 2569 — ถามฉันก่อนว่าต้องการทำอะไรก่อน
