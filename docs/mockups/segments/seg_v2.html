กลุ่มลูกค้า · เล่าเป็นภาพเคลื่อนไหว

ภาพตัวอย่าง · ตัวเลขสมมติ   ใช้กลุ่มเดิมของระบบ (ใหม่ / ทั่วไป / มาซ้ำ / มาบ่อย / หาย) เปลี่ยนแค่วิธีแสดงผล

1วันของลูกค้าแต่ละกลุ่ม

เลือกกลุ่ม แล้วกดเล่น ดูว่าเดินไปทีละช่วงอย่างไร ช่วงที่กระพริบแดงคือจุดที่ควรดูแลเป็นพิเศษ

ข้อมูลที่ระบบมีตอนนี้: เวลาเช็คอิน/เช็คเอาท์ และว่าสั่งอาหารเช้าหรือไม่ · ยังไม่มี: เวลาที่ลงไปกินอาหารเช้า (ถ้าอยากได้ ต้องให้พนักงานกดบันทึก)

2กลุ่มลูกค้าเปลี่ยนไปรายไตรมาส

ลากแถบหรือกดเล่น วงกลมของแต่ละกลุ่มโตหรือหดตามจำนวนคน

3เส้นทางของลูกค้า

จากทักมา → จอง → เข้าพัก → กลับมาซ้ำ แต่ละจุดคือลูกค้า 1 คน ไหลไปตามทาง ตรงที่หายไปคือตรงที่เสียลูกค้า

ข้อมูลที่ระบบมีตอนนี้: คนที่ทักมาทาง LINE, การจอง, การเข้าพัก, การกลับมาซ้ำ · ยังไม่มี: คนที่ "เห็นเรา" (เช่น เปิดดูเพจหรือแผนที่) จึงเริ่มนับตั้งแต่ทักมา
