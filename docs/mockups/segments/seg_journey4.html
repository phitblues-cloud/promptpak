ภาพตัวอย่าง v4 · ตัวเลขสมมติ · ยังไม่ได้ทำในระบบจริง
ปรับตามที่วงไว้:
  1. 3 กล่อง (เปอร์เซ็นต์ / ใช้จ่ายต่อคน / กลับมาซ้ำ) ขนาดเท่ากัน พอดีกัน เรียงขวาในกรอบ "กลุ่มนี้คือใคร"
  2. กล่องข้อมูลในภาพเล็กลงและอยู่ในท้องฟ้า ไม่ทับรูป
  3. ปุ่มหยุด/เริ่มใหม่ ย้ายไปมุมซ้ายบนของภาพ (เป็นไอคอนเล็ก)
  4. กดเลือกขั้นตอนเองได้: แตะ "จอง / ถึง / เช็คอิน …" ที่แถบล่าง ภาพจะหยุดที่ขั้นนั้นพร้อมกล่องข้อมูล · กด "เล่นต่อ" เพื่อให้เล่นต่อเอง
  5. ขั้นซักรีด/อาหารเช้าจะโผล่เมื่อกลุ่มนั้นใช้ตั้งแต่ 40% ขึ้นไป (กลุ่มลูกค้าบริษัทอาหารเช้า 35% จึงไม่มี)
